# Habit Tracker

A simple and effective habit tracking web app built with JavaScript. Track your daily routines, build consistency, and stay productive with a clean and intuitive interface.

## Features

- Add new habits
- Mark habits as complete or incomplete
- View habit progress over time
- Track recurring daily routines
- Simple and responsive design
- Data stored locally in the browser

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Demo

You can run the app locally in your browser by opening the project files or by serving it with a local web server.
